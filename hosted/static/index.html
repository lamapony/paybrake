Try the real extension

Chrome, Edge or Brave on a desktop. The extension reads the chat itself and makes a test order on this server.

  1. Download the zip and unzip it. You get a folder paybrake-extension with manifest.json inside.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and pick that folder. A Welcome to PayBrake tab opens. If Chrome says “Manifest file is missing”, go one folder deeper.
Download the extension (.zip) Open the store in extension mode

In the card: Switch to a PayPal order → Open approval → Approve (mock) → I approved it, capture. On a sandbox server, Open approval goes to PayPal’s sandbox page instead. Then check that three ordinary chats stay quiet.

What is real

No real money moves anywhere in this demo.

Rules check, on your device
The extension’s rules read the open chat in the browser. The cards in the demo store are what those rules return for each chat, word for word.
AI check, on the server
A second opinion from this server’s AI on the chat, masked in the browser first (emails, phones, card numbers, IBANs, codes). The key stays on the server. It has a per-visitor rate limit and a daily cap; when it is off or busy, PayBrake keeps working with its rules. AI check: on when the server key is set.
PayPal order
PayPal Orders v2 for Goods & Services: PayPal sandbox when the server has sandbox keys, otherwise a mock that follows the same steps. This server: sandbox when configured, otherwise mock.
