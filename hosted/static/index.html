PayBrake demo

A pretend marketplace for trying the PayBrake Chrome extension. Fictional people, test orders only, no real money.

Open the demo store

PayBrake needs to be installed in Chrome first. Not installed yet?

  1. Download paybrake-extension.zip from the project's GitHub release and unzip it.
  2. Open chrome://extensions and switch on Developer mode (top right).
  3. Click Load unpacked and pick the paybrake-extension folder (the one with manifest.json inside).
