Welcome page and demo store

Default is the free PayBrake test server (test orders only, no real money). Developers running npm run dev:backend can switch to localhost.

On: besides its built-in rules, PayBrake asks an AI model about every chat it checks, so it can also warn about scams the rules miss, such as fake bank or support messages, phishing links and requests for codes. The AI can also clear an obvious rules false alarm, but only when it is very sure.

Before any chat text leaves your browser, PayBrake masks emails, phone numbers, card numbers, IBANs (all but the last 4 characters), ID numbers and one-time codes. Only the other person's messages can trigger a warning, and your newest message is included for context. The masked chat goes to the server above, which passes it to its AI provider and keeps nothing.

The free test server has no AI provider (mock mode). With it, nothing is sent and warning cards say AI check off (mock server). If the AI does not answer within 6 seconds, the card shows AI check unavailable and the rules result stands.

Off: rules only. No chat text leaves your browser.
