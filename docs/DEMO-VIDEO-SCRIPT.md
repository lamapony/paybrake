# Demo video script (about 2 minutes)

Record either the hosted demo or the local mock, both described in the [README](../README.md). Use fictional demo chats. Do not record personal conversations or credentials. Button labels below match the current build. The hosted demo can show an **AI checked** tag once the server replies. The local mock, with no model configured, says the AI check is off.

| Time | Screen and narration |
| --- | --- |
| 0:00–0:20 | Show the marketplace chat. “A payment request can arrive in the middle of an ordinary conversation. PayBrake pauses at the point where someone is asked to pay.” |
| 0:20–0:45 | Show the bike thread and the extension card. Point to the four signals on that thread: Friends & Family, Upfront deposit, Pressure to hurry, and Ships before you meet. “The extension checks the chat on the device for concrete payment-risk signals. It explains what it found instead of interrupting every conversation.” |
| 0:45–1:20 | Select **Switch to a PayPal order**, open approval, approve the mock (or the PayPal sandbox page, if the server is on sandbox), return and capture. “Here we can start an order for the item. This approval and capture is a sandbox or a local simulation: no real money moves. Eligibility for Buyer Protection depends on PayPal's terms.” |
| 1:20–1:40 | Open the safe chats page, or scroll to the lamp thread. “Ordinary conversations stay quiet in these examples. Detection is limited to the patterns and languages implemented, and can miss scams.” |
| 1:40–2:00 | Return to the card and README. “PayBrake is a prototype by Dima, Christopher and David. Judges can run the hosted demo, or this same credential-free local mock, from the README.” |
