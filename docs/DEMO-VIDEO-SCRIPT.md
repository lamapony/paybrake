# Demo video script (about 2 minutes)

Record the local mock flow with Chrome, the extension loaded, and both servers running as described in the [README](../README.md). Use fictional demo chats; do not record personal conversations or credentials.

| Time | Screen and narration |
| --- | --- |
| 0:00–0:20 | Show the marketplace chat. “A payment request can arrive in the middle of an ordinary conversation. PayBrake pauses at the point where someone is asked to pay.” |
| 0:20–0:45 | Show the bike thread and the extension card. Point to its evidence. “The extension checks the chat on the device for concrete payment-risk signals. It explains what it found instead of interrupting every conversation.” |
| 0:45–1:20 | Select **Move to protected PayPal order**, open approval, approve the mock, return and capture. “Here we can start an order for the item. This entire approval and capture is a local simulation: no PayPal account or money is involved. Eligibility for Buyer Protection depends on PayPal's terms.” |
| 1:20–1:40 | Open the safe chats page. “Ordinary conversations stay quiet in these examples. Detection is limited to the patterns and languages implemented, and can miss scams.” |
| 1:40–2:00 | Return to the card and README. “PayBrake is a prototype by Dima, Christopher and David. Judges can run this same credential-free mock using the README.” |
